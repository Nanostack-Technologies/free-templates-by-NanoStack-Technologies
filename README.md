Each template includes:<br>

• README.md — instructions and features<br>
• index.html or project folder — the actual code<br>
• Live demo link (when available)<br>

🧭 How to Use<br>
Option 1 — Clone directly<br>
git clone https://github.com/NanoStackTechnologies/free-website-templates.git<br>

Option 2 — Download a single template<br>
Browse to the /templates folder.<br>
Choose your industry (e.g. /cafe, /school).<br>
Download or copy the code.<br>
Customize with your content.<br>
Deploy using Vercel, Netlify, or your preferred host.<br>
